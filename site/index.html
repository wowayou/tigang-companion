开始训练 如何安装

此刻,已经有人在练

节奏引导

收紧 / 维持 / 放松三段,配方向性提示音与倒计时,闭着眼也能跟着做。

打卡与连续

每天一次,连续天数与热力图看得见;成就徽章激励你坚持。

隐私优先

默认只存在你的设备上;可导出备份,也可主动开启只上传密文的多端同步。

免费 · 无广告

零依赖、零注册。安装到主屏后离线也能用,同步服务不可用时不影响训练。

安装到主屏,像原生 App 一样用

1

iOS Safari:点击分享按钮 → 添加到主屏幕。

2

Android Chrome:菜单 → 安装应用 / 添加到主屏幕。

3

桌面浏览器:直接用,或地址栏旁的「安装」图标。

隐私说明

训练打卡数据默认只保存在本机浏览器。只有你主动开启同步时,应用才会把由主密码端到端加密后的密文上传到自建服务;主密码不离开设备。顶栏「此刻多少人在做 · 总访问」只向自建计数服务上报随机 ID 和页面加载次数,不使用第三方统计。

训练方案参考 Mayo Clinic 与 NHS 的盆底肌训练公开建议。本应用仅供健康锻炼参考,不构成医疗建议;急性痔疮发作期、盆底肌过度紧张或术后恢复期请先咨询医生。
