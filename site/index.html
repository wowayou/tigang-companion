开始训练 如何安装

此刻,已经有人在练

节奏引导

收紧 / 维持 / 放松三段,配方向性提示音与倒计时,闭着眼也能跟着做。

打卡与连续

每天一次,连续天数与热力图看得见;成就徽章激励你坚持。

隐私本地

所有记录只存在你的设备上,可随时导出备份;不引第三方统计。

免费 · 无广告

零依赖、零后端、零注册。安装到主屏后离线也能用。

安装到主屏,像原生 App 一样用

1

iOS Safari:点击分享按钮 → 添加到主屏幕。

2

Android Chrome:菜单 → 安装应用 / 添加到主屏幕。

3

桌面浏览器:直接用,或地址栏旁的「安装」图标。

现在就去练

隐私说明

训练打卡数据只保存在本机浏览器,不会上传,可随时导出备份或清除。顶栏那行「此刻多少人在做 · 总访问」是全站计数,只向我们的计数服务上报一个随机 ID 和页面加载次数,不收集任何个人身份信息,也不经过任何第三方统计服务。

换了域名,旧记录还在吗

浏览器按域名隔离数据,旧地址 wowayou.github.io 的记录不会自动跟到新域名,而且旧地址现在会直接跳转到本站。
如果你之前导出过备份文件,在应用里「统计 → 数据管理 → 导入备份」即可恢复;否则从今天开始记录也很好。

训练方案参考 Mayo Clinic 与 NHS 的盆底肌训练公开建议。本应用仅供健康锻炼参考,不构成医疗建议;急性痔疮发作期、盆底肌过度紧张或术后恢复期请先咨询医生。
